Graph Theory Concepts

1. Graph

A graph is a mathematical structure consisting of vertices and edges.

2. Vertices (V)

Vertices represent university locations.

V = {University Gate, O Building, S Building, Saffron Canteen, Y Building (Library)}

3. Edges (E)

Edges represent direct connections between locations.

E = {(Gate,O), (O,S), (S,Saffron), (Saffron,Y), (O,Saffron), (O,Y)}

4. Degree

The degree of a vertex is the number of edges connected to it.

Gate = 1, O Building = 4, S Building = 2, Saffron Canteen = 3, Y Building = 2.

5. Path

A path is a sequence of vertices connected by edges.

University Gate → O Building → S Building → Saffron Canteen → Y Building (Library)

6. Breadth-First Search (BFS)

BFS explores vertices level by level and finds a path with the fewest edges in an unweighted graph.
